# Wallpapers

This package tracks the Pink Floyd Gruvbox wallpaper:

```text
wallpapers/.local/share/wallpapers/pink-floyd-gruvbox-dark.jpg
```

`just stowall` deploys it to `~/.local/share/wallpapers/`.

Apply only the wallpaper:

```bash
just wallpaper
```

Apply the wallpaper together with dark mode and the Gruvbox-inspired macOS
accent color:

```bash
just macos-gruvbox
```
